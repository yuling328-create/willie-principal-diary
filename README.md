# 威利兄弟 3.0｜園長日記系統

一套可直接部署到 GitHub Pages 的 A4 直式園長日記產生器。每個月只要更新出刊資訊、貼上家長原文，就能整理成風格一致的園長日記。

## 目前功能

- 固定品牌 Banner：`威利兄弟3.0｜一起玩`
- 年份、月份、園長、孩子資料與紀錄期間可自由修改
- 本期主題可自由修改，預設為「陪你一起孵出英語母語寶寶」
- 貼上家長原始日記後，自動拆成 4–7 個主題段落
- 每段可自行改標題、圖示、內文、順序，也可新增或刪除
- 依內容關鍵字搭配固定童趣圖示
- 內建 12 款「威利兄弟 3.0」原創童趣插圖，可逐段選擇或自動配圖
- 最上方主圖可選擇不顯示、內建素材或自行上傳；不顯示時自動收合版面
- 日期統一使用「紀錄期間」，避免與上方月份及出刊資訊重複
- 內建主圖統一使用固定插畫框，維持長寬比例並避免尺寸忽大忽小
- 段落插圖固定排在文字下方，不會遮住日記內容
- 內建六種輸出版型：「可愛月刊、日記故事、情境觀察、手足成長、活動拼貼、園長條列」
- 可填寫第二位孩子，並指定每個段落屬於第一位、第二位或共同紀錄
- 每段可設定段落類型及日期／小標，切換版型時內容仍可繼續使用
- 可快速加入「本月亮點、家長反思、日期情境、歌曲紀錄、英文金句、園長提問、下個月計畫」
- 可上傳家庭主圖
- A4 直式比例即時預覽，卡片區會自動延展，避免頁尾過度留白
- 幼稚園系奶油手繪 Banner，搭配熊熊、時鐘、氣球、花草與紙膠帶裝飾
- 放大品牌 Banner 與「園長日記」主標題，讓頁首形成清楚的主視覺區
- 內建蜜桃粉、嫩芽綠、陽光黃、天空藍四種可愛配色，可隨每期主題切換
- 下載 PNG、列印或另存 PDF
- 一鍵下載標準 A4 單頁 PDF，長內容會等比例縮放而不會被切成兩頁
- 草稿儲存在使用者自己的瀏覽器
- 支援手機、平板與電腦瀏覽

## 使用方式

直接開啟 `index.html` 即可使用。若瀏覽器限制本機功能，可在資料夾內啟動簡易伺服器：

```bash
python -m http.server 8000
```

再開啟 `http://localhost:8000`。

## 發布到 GitHub Pages

1. 將本專案推送到 GitHub 儲存庫。
2. 進入儲存庫的 **Settings → Pages**。
3. 在 **Build and deployment** 的 Source 選擇 **GitHub Actions**。
4. 推送到 `main` 後，`.github/workflows/pages.yml` 會自動發布網站。

## AI 整理與插圖說明

未設定後端時，「AI／智慧整理」會在瀏覽器本機以規則整理內容，不會把日記傳到外部服務。

如需真正的 AI 改寫，可在畫面填入自己的安全後端網址。前端會呼叫：

```text
POST {AI_API_PROXY}/organize
```

回傳格式：

```json
{
  "sections": [
    {
      "title": "聽熟之後，自然開始跟著說",
      "text": "整理後的日記內容",
      "icon": "🎵",
      "imageUrl": "https://example.com/illustration.png"
    }
  ],
  "closing": "本月最想留下的一句話"
}
```

`imageUrl` 為選填欄位。回傳安全的 HTTPS 圖片網址後，選擇「AI 插圖（需後端）」即可顯示；若未提供圖片，系統會自動使用童趣圖示。

請勿將 OpenAI API Key 或其他密鑰直接寫入 HTML、JavaScript 或 GitHub 公開儲存庫。

## 資料隱私

- 本機規則整理、編輯與草稿儲存都在瀏覽器內完成。
- 只有使用者自行填入 AI API Proxy 並按下整理時，日記內容才會送至該後端。
- 發布前請確認照片與孩子姓名已取得適當使用同意。
